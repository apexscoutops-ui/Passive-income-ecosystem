Architecture notes

How this is calculated
  • Average QPS = users × queries per user ÷ 86,400 seconds.
  • Peak QPS = average QPS × peak multiplier.
  • Peak IOPS = peak QPS × (1 + 2 × write ratio). Writes count double to cover WAL and index updates.
  • Throughput = peak IOPS × 4 KB per operation.

This is a planning heuristic, not a benchmark. Validate against load tests on your real schema.
